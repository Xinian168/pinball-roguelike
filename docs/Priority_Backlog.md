# 优先级清单

## 优先级定义

| 等级 | 定义 |
|---|---|
| **P0** | 不做这个就不是这个游戏 |
| **P1** | 做了这个核心乐趣才完整 |
| **P2** | 做了能让游戏更耐玩 |
| **P3** | 做了能让游戏更"高级"，但删了不影响核心 |

## 功能清单

| 功能名 | 优先级 | 一句话理由 |
|---|---|---|
| 核心发射：瞄准 + 蓄力 + 发射 | P0 | 核心循环第一环，没有"我来决定打哪"就没有玩家意图 |
| 袋洞（进球判定 + 计分） | P0 | "进不进袋洞"是整个循环的悬念来源，是游戏的"赢"本身 |
| 球数（生命/弹药）管理与结算 | P0 | "球数保没保住"是循环的情绪钩子，没有代价就没有决策重量 |
| 单局循环：发射→结算→再来一局 | P0 | 把五个环节闭合成环，缺一环就不是"循环" |
| 回合制瞄准（逐颗发射，非按住连喷） | P0 | 连喷是测试器不是游戏；一次一颗才能承载"瞄准→蓄力"的心跳感 |
| 袋洞奖励梯度（不同洞不同分/不同奖励） | P1 | 让"看球弹"从纯观赏变成对结果的期待，是乐趣的放大器 |
| 肉鸽层：三选一祝福/诅咒（局内 build） | P1 | "肉鸽"二字的立足点，让每局产生不同的打法倾向 |
| 局内货币 + 简易商店/重掷 | P1 | 把"进洞"转化为"选择权"，构成"运气→策略"的转化链 |
| 可累积的局外成长（解锁球种/图钉改造） | P1 | 给"再来一发"一个跨局理由，是肉鸽留存的基本盘 |
| 图钉阵多样化（每局随机排布/障碍变体） | P1 | 没有随机图钉阵第二局就腻；它是肉鸽重玩性的物理载体 |
| 球的多球策略（分裂球、连锁球等球种） | P2 | 加宽单局策略面，但第一颗球好玩之前不需要更多球 |
| 特殊图钉（倍率钉、触发器、移动钉） | P2 | 提升弹跳过程的可读性与计划性，让物理乱流变成"可计算的赌局" |
| 连击/同杆多洞奖励（Pinball 风格连奖） | P2 | 强化"看球弹"过程的紧张感，是耐玩度而非成立条件 |
| 失败/胜利条件与局末结算画面 | P2 | 把循环终点仪式化；前期用"球打完=局结束"也能凑合 |
| 音效与打击反馈（进洞音、弹钉声） | P2 | 弹珠游戏的爽感一半在耳朵里，但视觉先行也能玩 |
| 视觉主题（Pachinko 机框、灯光、演出） | P3 | 明显提升"高级感"，柏青哥的灵魂氛围，但白盒已能验证乐趣 |
| 球路预测线/辅助瞄准 | P3 | 好用但可能杀死弹珠的赌博感，适合做成可开关的辅助 |
| 每日挑战 / 种子分享 | P3 | 社区与长线留存层，核心闭环稳固后再谈 |
| 元进度（任务、成就、图鉴） | P3 | 锦上添花，删了不影响任何一局 |

## 发射方向

- 基础方向：发射器指向鼠标光标（`get_global_mouse_position() - global_position`，归一化）
- 兜底：光标贴发射器上（距离 < 1.0）时默认 `Vector2.UP`，避免零向量
- 随机偏移：**已移除**（原 `launch_angle_jitter_deg=15.0` 随 A 阶段 2026-10-13 鼠标瞄准改造一起删，无人提过要保留抖动）

## 已有但属于测试遗留、待改造的规则

- 无（连发/悬停开火已随蓄力版发射器移除，2026-10-12）

## 一局规则（MVP）——2026-10-12 拍板 / 2026-10-13 A 阶段实现

> 本节为 MVP 玩法的权威数值，实现代码必须与之一致；改动需走决策记录流程。
> 2026-10-13 A 阶段实现落地：`RoundController` 节点 + `Pockets`（3 个袋洞）+ `NormalZone`（4 段普通区）+ `SettlePanel`。

- 起始球数：**50**。
- 一局倒计时：**90 秒**。
- 进入下一局阈值：球数 **≥ 60**。
- 倒计时归零未达阈值：本局失败，球数重置为 **50**。
- 玩家可随时点「结算」按钮提前结束本局。
- 击中钉子：不奖励球，不扣球（钉子只影响弹道）。
- 球落到屏幕底部「普通区域」：球数 **-1**，仅此而已。
- 球落到屏幕底部「奖励袋洞」：球数 **+3**。
- 每次发射扣 `fire_cost` 球（默认 1）—— v2 新增规则，2026-10-13 落地。

### 各项规则实现状态（2026-10-13）

| 概念 | 数值 | 实现 | 备注 |
|---|---|---|---|
| 起始 / 阈值 / 重置 | 50 / 60 / 50 | ✅ `RoundController` | `start_balls` / `target_balls` / `start_round()` |
| 一局倒计时 | 90 秒 | ✅ `RoundController` | `round_seconds`；**timer 归零后延迟 settle**（决策 #3，见下「结算时机」行） |
| 每次发射扣球 | 1 | ✅ `RoundController` | `fire_cost`，`launcher._fire()` 成功后调 `spend_ball()` |
| 奖励袋洞 | +3 + 飘字 | ✅ `Pockets`（3 个 Area2D） + `FloatingText` | `pocket.gd` → `rc.register_pocket_drop()` + spawn `FloatingText` 显示 `+N`；位置见 `04_physics.md` |
| 结算时机 | timer 归零 + live_balls==0 | ✅ `RoundController._check_settle()` | 决策 #3：timer 一到 0 不立即 settle，等所有在飞球落地再结算；其他路径（球数=0+场上无球、手动点结算）行为不变 |
| 普通区域 | -1 | ❌ **未启用**（A 阶段范围外） | v2 规则保留 -1 数值；A 阶段实现为「仅清理，不扣球」（`normal_zone.gd` 直接 `queue_free`） |
| 结算按钮 | 提前结束本局 | ✅ `Hud/SettleButton` | 触发 `rc.end_early()` → `settle()` |
| 倒计时显示 | 90 秒倒计时 | ✅ `Hud/TimerLabel` | 实时显示，settled 时隐藏 |
| 结算画面 | 达标「进入下一局」/ 未达「本局失败」 | ✅ `Hud/SettlePanel` | 两种按钮均触发 `start_round()` 重启（v2 范围声明不实现下一局内容） |
| 多局结构 | 失败重置 50 / 成功当前仅重启 | ❌ | 「进入下一局」按钮当前语义 = 重启一局；真实下一局内容（难度递进 / 祝福）属 P1，未实现 |

### v2 落地后仍未定的项

- **普通区 -1 何时启用**：v2 规则保留数值定义，但 A 阶段（2026-10-13）实现为不扣球。是否恢复扣球行为需走决策记录。
- **多局难度递进**：**待定**（按 MVP 范围声明不在 MVP 内）。
- **袋洞奖励梯度（多级分值）**：**待定**（当前 MVP 仅有 +3 一档；多级分值属 P1）。
- **袋洞布局随机化**：当前固定 3 个（x=480/960/1440, y=1035）；多局随机布局属 P1「图钉阵多样化」，未实现。

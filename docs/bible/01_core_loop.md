# 01_core_loop.md — 核心循环

> 来源：`docs/Core_Loop.md`（唯一权威描述）+ 当前工程实现状态。
> 改发射、袋洞、结算、重开等循环相关功能前必读。

## 循环描述（≤100 字）

玩家在 90 秒一局的限时内，瞄准并蓄力发射弹珠，看它在图钉阵中弹跳翻滚：落入奖励袋洞球数 +3，落入普通区域球数 -1，钉子只影响弹道。局末以球数定成败——≥60 进入下一局，否则重置 50 再来。球数的涨落驱动每一发的取舍。

## 循环图

```
瞄准 → 蓄力 → 发射 → 看球弹 → 看进袋洞 → 看球数变化
     → (90 秒倒计时归零 / 点结算提前结束)
          球数 ≥ 60 → 进入下一局 ──┐
          球数 < 60 → 失败，重置为 50 ──┴→ (回到瞄准)
```

> 多局结构依据：`03_rules.md`「一局规则（MVP）」（2026-10-12 拍板，见决策 #2）。

## 当前实现状态（2026-10-13，A 阶段后）

| 环节 | 状态 | 现状 |
|---|---|---|

**结论**：A 阶段（2026-10-13）后核心循环已闭环——瞄准→蓄力→发射→看球弹→看进袋洞→看球数变化→想再来一发→重开 全部接通。下一阶段做肉鸽三选一祝福（P1）把「拿奖励」一环接上。

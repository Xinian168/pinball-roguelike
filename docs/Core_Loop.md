# 核心循环

## 一、循环描述

玩家在 90 秒一局的限时内，瞄准并蓄力发射弹珠，看它在图钉阵中弹跳翻滚：落入奖励袋洞球数 +3，落入普通区域球数 -1，钉子只影响弹道。局末以球数定成败——≥60 进入下一局，否则重置 50 再来。球数的涨落驱动每一发的取舍。

## 二、循环图

```
瞄准 → 蓄力 → 发射 → 看球弹 → 看进袋洞 → 看球数变化
     → (90 秒倒计时归零 / 点结算提前结束)
          球数 ≥ 60 → 进入下一局 ──┐
          球数 < 60 → 失败，重置为 50 ──┴→ (回到瞄准)
```

## 三、动词 → 关键功能映射

| 循环动词 | 对应关键功能（引自优先级清单） |
|---|---|
| **瞄准** | 核心发射：瞄准 + 蓄力 + 发射（P0）；回合制瞄准（P0） |
| **蓄力** | 核心发射：瞄准 + 蓄力 + 发射（P0）；球路预测线/辅助瞄准（P3，可开关） |
| **发射** | 核心发射：瞄准 + 蓄力 + 发射（P0）；球的多球策略（P2） |
| **看球弹** | 图钉阵多样化（P1）；特殊图钉（P2）；音效与打击反馈（P2） |
| **看进袋洞** | 袋洞（进球判定 + 计分）（P0）；袋洞奖励梯度（P1）；连击/同杆多洞奖励（P2） |
| **看球数变化** | 球数（生命/弹药）管理与结算（P0）；失败/胜利条件与局末结算画面（P2） |
| **拿奖励/选祝福** | 肉鸽层：三选一祝福/诅咒（P1）；局内货币 + 简易商店/重掷（P1） |
| **想再来一发** | 单局循环：发射→结算→再来一局（P0）；可累积的局外成长（P1）；视觉主题（P3） |
